# Security Policy / Политика безопасности

## Supported versions / Поддерживаемые версии

Only the latest release receives fixes. / Исправления выходят только для последнего релиза.

## Reporting a vulnerability / Как сообщить об уязвимости

**Please do not open a public issue.** Use GitHub's private
[Report a vulnerability](https://github.com/user110611/SimpleWarnAnalyzer/security/advisories/new) form.
Describe the problem, the steps to reproduce it and the affected version.

**Не создавайте публичную задачу.** Воспользуйтесь закрытой формой
[Report a vulnerability](https://github.com/user110611/SimpleWarnAnalyzer/security/advisories/new)
и опишите проблему, шаги воспроизведения и версию.

The local web interface listens on `127.0.0.1` only and is protected by a per-run token; reports about bypassing it are especially welcome.
